# 方寸看盘

[打开方寸看盘网页版](https://fan-pointer.github.io/fangcun-kanpan/)

在首页切换 A 股和美股，可以看到两市各自市值前 50 只股票的云图。方块面积对应市值，颜色对应涨跌。点击个股可查看行情日期、来源，并加入本机自选。

「全球」收录 28 个市场主题，以及有色金属和宏观指标。「龙虎榜」展示披露的买卖席位和净买额，「龙头」按连板数与成交额排列。每份榜单独立标注交易日期。主题、基金、ETF 和宏观栏为参考快照。

## 行情更新

GitHub Actions 在周一至周五 UTC 每小时的第 17、47 分钟定时构建网页，运行时间由 GitHub 调度。市值榜、龙虎榜和连板榜从公开行情源读取。上游暂不可用时沿用最近可用的快照与交易日期。生成的网页和四份 JSON 由 GitHub Pages 提供，自选保存在浏览器本地。

## 本地运行

打开 `preview.html` 即可浏览内置快照。安装 Node.js 24 后，在项目根目录运行 `node deploy/build-site.cjs` 可生成含更新数据的 `_site/index.html` 和 `_site/data/`。
