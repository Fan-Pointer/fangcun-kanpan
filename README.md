# 方寸看盘

[打开方寸看盘网页版](https://fan-pointer.github.io/fangcun-kanpan/)

在首页切换 A 股和美股，可以看到两市各自市值前 50 只股票的云图。方块面积对应市值，颜色对应涨跌。点击个股可查看行情日期、来源，并加入本机自选。

「全球」展示 11 只美股上市 ETF 的报价，并保留 28 个市场主题和有色与宏观的历史参考快照。「龙虎榜」展示披露的买卖席位和净买额，「龙头」按连板数与成交额排列。每份榜单独立标注交易日期。

## 行情更新

手机或电脑打开网页后，浏览器直接向腾讯行情请求 A 股、美股及市场 ETF 的最新报价。常规交易时段约每 15 秒查询一次，其余时段约每 60 秒查询一次。可点击「刷新行情」立即查询，切到后台会暂停轮询。云图、股票详情和榜单共用各股的价格、涨跌幅与市值。时间来自行情源，A 股显示北京时间，美股显示美东时间。免费源可能有延迟，休市时保留最近报价。行情连接失败会保留最后一份可用数据。

全市场前 50 的入选名单和披露榜单通过 GitHub Actions 在周一至周五 UTC 每小时的第 17、47 分钟计划更新。两次构建之间，网页在已公布的 50 只成分股内按最新可用市值重新排序。龙虎榜和连板榜以披露日期为准。首页的 3 只美股指数 ETF 和全球页的 11 只市场 ETF 联网更新，历史主题、汇率、宏观和基金数据标注参考快照或净值日期。网站无需数据库，自选保存在当前浏览器。

## 本地运行

打开 `preview.html` 即可浏览内置快照。安装 Node.js 24 后，在项目根目录运行 `node deploy/build-site.cjs` 可生成含更新数据的 `_site/index.html` 和 `_site/data/`。
